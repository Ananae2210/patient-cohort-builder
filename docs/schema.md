# Database schema (`data/cohort.db`)

800 synthetic patients in Massachusetts. Everything is fake, generated by `data/generate_data.py`. Column names follow Synthea's CSV export (lower-cased). **Treat 2026-11-01 as "today"** when you work out ages.

Later, this file becomes part of the prompt you send to the LLM, so keep it accurate if you change the data.

## patients (800 rows), one row per person

| column | example | notes |
|---|---|---|
| id | `a3f1…` | primary key (UUID text) |
| birthdate | `1971-04-09` | ISO date text |
| deathdate | NULL | always NULL in this dataset |
| first, last | `Asha`, `Iyer` | fake names |
| gender | `F` / `M` | single letter |
| race | `white`, `black`, `asian`, `hispanic`, `other` | |
| city, state | `Boston`, `Massachusetts` | 6 cities |

## conditions (1,228 rows), diagnoses

| column | notes |
|---|---|
| start | date the diagnosis was made |
| stop | NULL means still active |
| patient | → patients.id |
| code | SNOMED-CT code (filter on this, not the description) |
| description | human-readable name |
