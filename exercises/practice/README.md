# Practice copies

These are the original blank starter files, with TODOs only. The working app in `src/`, `eval/` and `app.py` was built by Claude.

To learn by doing, write your own version here first, then compare it with the working version. The "Done when" checks in the main README still apply.

Paths inside these files assume they live in `src/` or the project root. If you run one from this folder, change `DB_PATH` to:
`Path(__file__).resolve().parent.parent.parent / "data" / "cohort.db"`
